# 🎯 Kotlin Goal Setter

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=for-the-badge&logo=kotlin&logoColor=white)
![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)

A **simple, clean Android application built with Kotlin** that helps users set and stay focused on their personal goals.  
This project represents my **first Kotlin-based Android app**, created to learn core Android fundamentals with real-world logic.

---

## 📱 Overview

**Kotlin Goal Setter** allows users to create, view, and manage goals in a distraction-free interface.  
The app focuses on **clarity, usability, and clean code**, making it a solid foundation for future Android projects.

---

## ✨ Features

- 📝 Create and manage personal goals  
- 🎯 Minimal & focused UI  
- ⚡ Lightweight and fast  
- 📱 Native Android experience  
- 🧠 Beginner-friendly Kotlin structure

▶️ Getting Started

1) Clone the repository : git clone https://github.com/Pranav-chaudhari-2006/Kotlin-Goal-Setter
2) Open the project in Android Studio
3) Allow Gradle to sync dependencies
4) Run the app on: Android Emulator, or Physical Android device
